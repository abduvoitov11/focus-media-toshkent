## 📌 Loyiha Haqida

**Focus Media** — Toshkent viloyati umumta'lim maktablarida zamonaviy axborot makonini shakllantirish, o'quvchi-yoshlarning media-savodxonligini oshirish, kiber-xavfsizlik madaniyatini shakllantirish va yoshlar iqtidorini butun respublikaga namoyish etishga qaratilgan innovatsion raqamli media platforma.

Mazkur loyiha Toshkent viloyati hokimligi, Maktabgacha va maktab ta'limi boshqarmasi hamda faol yoshlar tashabbusi asosida ishlab chiqilgan taqdimot negizida to'liq professional vebsaytga aylantirildi.

## 🚀 Taqdimotga Nisbatan Kiritilgan Innovatsiyalar va Boyitishlar

Asl PPTX taqdimot loyiha konsepsiyasini o'z ichiga olgan edi. Biz uni tahlil qilib, amaliyotda to'laqonli ishlashi uchun barcha zarur bo'lgan interaktiv tizimlar bilan boyitdik:

1. **🤖 Interaktiv Telegram "Focus Bot" Simulyatori:**
   - Foydalanuvchi va o'quvchilar real vaqt rejimida bot funksiyalari (So'nggi yangiliklar, Qalqon testi, Podkastlar, Murojaat yo'llash) bilan bevosita saytda muloqot qila oladi.

2. **🎙️ "Focus Suhbat" Ovozli Podkast Pleeri:**
   - Zamonaviy ovoz to'lqinlari (sound waves), audio boshqaruv va pleylist simulyatori.

3. **🏆 "Viloyat Iftixorlari" Interaktiv Zali (Hall of Fame):**
   - Xalqaro va respublika olimpiadachilari, Yosh dasturchilar, Chempion sportchilar va San'at yulduzlari uchun toifali filtrlash tizimi.

4. **🛡️ "Kiber-Qalqon" Bilim Sinovi (Interactive Cyber Quiz):**
   - O'quvchilar fishing, soxta havolalar va internet xavfsizligi bo'yicha savollarga javob berib, darhol o'z bilim darajasini tekshirishi mumkin.

5. **🗺️ Toshkent Viloyatining barcha 22 ta tuman va shaharlari qamrovi:**
   - Har bir tuman/shahar (Chirchiq, Olmaliq, Angren, Bo'stonliq, Zangiota va b.) bo'yicha maktablar soni va media guruhlar faolligi statistikasi.

6. **📝 Maktablarni Loyihaga Qo'shish Onlayn Arizasi:**
   - Har bir maktab ma'muriyati yoki yetakchisi o'z maktabini Focus Media tarmog'iga ulash uchun onlayn buyurtma qoldira oladi.

7. **❓ Keng qamrovli FAQ (Savol-Javoblar):**
   - Loyihani joriy etish, studiya jihozlari, o'quvchilar qabuli va ota-onalar nazorati bo'yicha to'liq ma'lumot beruvchi interaktiv akkordeon.

8. **🪐 Three.js 3D Interaktiv Kosmik/Zarrachalar Foni:**
   - Sichqoncha harakatiga moslashuvchi, zamonaviy kiber-makon hissi beruvchi WebGL 3D zarrachalar foni.

9. **🔊 Web Audio API Ovoz Effektlari:**
   - Tugmalarni bosganda futuristik nozik chertish va bosish tovushlari (yoqish/o'chirish imkoniyati bilan).

10. **🌓 Dark/Light Rejim:**
    - Bir marta bosish orqali qulay tungi yoki kunduzgi ko'rinishga o'tish imkoniyati.

## 🛠️ Ishlatilgan Texnologiyalar

- **Frontend:** Semantic HTML5, CSS3 Custom Properties (Variables), Vanilla JavaScript (ES6+)
- **3D Graphics & FX:** Three.js (WebGL), Canvas 2D
- **Audio:** Web Audio API (Sintezlangan zamonaviy micro-interactions)
- **UI Design System:** Glassmorphism, Neon Cyberpunk accents, Responsive Grid & Flexbox
- **Icons & Fonts:** FontAwesome 6, Google Fonts (Syne, Plus Jakarta Sans)
- **Hosting & CI/CD:** GitHub Pages

## 💻 Mahalliy Muhitda Ishga Tushirish

Loyihani o'z kompyuteringizda ishga tushirish juda oson:

```bash
# 1. Repozitoriyni klonlash
git clone https://github.com/abduvoitov11/focus-media-toshkent.git

# 2. Loyiha papkasiga o'tish
cd focus-media-toshkent

# 3. Brauzerda ochish (yoki istalgan lokal server yordamida)
# Masalan Python orqali:
python3 -m http.server 8080
```
Brauzerda `http://localhost:8080` manziliga o'ting.
